Utmaningen

Vanliga att göra-listor klarar inte projekt med deluppgifter. Jag behövde ett verktyg som visar hur långt ett projekt kommit, med uppgifter i flera nivåer och tydliga statusar — utan att kännas tungt eller byråkratiskt.

Det jag byggde

  • Kanban-bräde i fyra steg: Att göra, Pågår, Granskning, Klar
  • Nästlade uppgifter i tre nivåer med progress per projekt
  • Inline-redigering som sparar automatiskt
  • Deadlines med nedräkning och visuell varning
  • Fullskärmsläge för fokuserat arbete
  • Profiler och realtidssync via Supabase
